Lab 02: JSX Fragments

Task 1: Create and use React components that utilize JSX fragments to group multiple elements without adding extra nodes to the DOM. Implement components such as ItemList and FragmentLayout, and combine them in a parent component.

Task 2: Refactor components to accept props and render dynamic content using fragments. Pass data from a parent component to child components and display totals or lists accordingly.

Task 3: Explore advanced fragment usage, such as using keys with fragments in lists, and ensure components remain clean and efficient without unnecessary wrapper elements.
