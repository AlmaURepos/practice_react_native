### Команды запуска (локально)

Для task1:

```bash
cd lab-10/task1
npm install
npm run dev
```

Сборка production:

```bash
cd lab-10/task1
npm run build
```

Запуск тестов:

```bash
cd lab-10/task1
npm test
```

или

```bash
cd lab-10/task1
npm test -- --runInBand
```
